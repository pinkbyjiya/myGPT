# MyGPT

MyGPT is an interactive web application built using Python and Streamlit that demonstrates the use of GPT-style models for text generation based on user prompts.

The project focuses on understanding how language models can be integrated into applications, along with building a simple and clean user interface for interaction.

## Features

- User-friendly interface for entering text prompts
- Dynamic text generation using GPT-style models
- Clean and readable code structure
- Simple and responsive UI using Streamlit

## Tech Stack

- Python
- Streamlit
- GPT-style API
- HTML/CSS (basic styling)
